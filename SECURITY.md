# Security and privacy

This is an early pattern-matching prototype, not a certified anonymisation system.
Review its output manually and preserve confidential originals in appropriate storage.

Report a suspected data-exposure defect privately to nabila@nabilaws.com.
Provide synthetic reproduction steps only. Do not attach client files or personal data.
The project does not promise a response deadline or offer a bug bounty.

The tool supports plain text only and cannot remove PDF layers, Word metadata,
embedded images, or file-system history. Keep confidential files out of GitHub.
